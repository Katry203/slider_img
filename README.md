# 🖼️ Dynamic JavaScript Image Slider

A fully dynamic image slider built using **HTML**, **CSS**, and **pure JavaScript**.  
All functionality — including navigation, image loading, and counter — is powered by JavaScript with **no hardcoded HTML slides**.

![Slider Screenshot](./screenshot.png)

---

## 🚀 Features

- ✅ Dynamic slide rendering from JavaScript
- ✅ Slide counter: `slide# X of N`
- ✅ Next/Previous buttons
- ✅ Pagination bullets (numbers) to jump between slides
- ✅ Active slide highlighting
- ✅ Clean, responsive UI

---

## 🔧 Technologies Used

- HTML5
- CSS3 (Flexbox + basic styling)
- Vanilla JavaScript

---

## 🧠 How It Works

- All images are stored in an array or list in JavaScript.
- The slider UI (image, counter, pagination) is generated and updated completely through JS.
- Event listeners on buttons and page numbers dynamically update the active slide.
